package schemaregistry // import "github.com/faustbrian/go-schema-registry/v3"

Package schemaregistry provides explicit schema compilation, scoped provider
clients, cache/bundle/graph resolution and codec/framer composition. Start with
Compile and an explicit format canonicalizer, then NewClient/NewResolveCache
or NewBundle as needed. Schema/Bundle values own copied data; clients/cache own
synchronized local state but no background goroutines or collaborator shutdown.

Portable identity is this package's SHA-256 profile, not a provider ID,
authenticity proof or universal compatibility relation. Local-only
canonicalizers/codecs are collaborator obligations, not an I/O sandbox.
Context cannot forcibly interrupt callbacks, and per-owner limits do not bound
total process memory, waiters or deployment demand. Root /v3 and Confluent
/v3 types differ from Glue's retained /v2 cohort. Exact language/source
versions and SCHEMA-REG-DEC-001..004 are in specification/README.md and
spec/sources.lock.json.

type Bundle struct {
	// Has unexported fields.
}
    Bundle is an immutable, content-addressed graph for startup and offline use.
    Resolution performs no network access.

func LoadBundle(
	ctx context.Context,
	encoded []byte,
	canonicalizers map[Format]Canonicalizer,
	limits GraphLimits,
	maxBundleBytes int,
) (Bundle, error)
    LoadBundle validates and recompiles a bounded artifact with caller-supplied
    local canonicalizers. Canonicalizers must not perform network access;
    this is a collaborator obligation, not a sandbox. Encoded length precedes
    JSON parsing, but schema-count/graph and canonical-output limits follow
    materialization. Unknown fields/trailing values fail; duplicate JSON keys
    follow encoding/json, not a duplicate-key rejection policy. Every claimed
    hash is recomputed, not authenticated. Context does not interrupt arbitrary
    canonicalizer work.

func NewBundle(
	root Schema,
	dependencies []Schema,
	limits GraphLimits,
	provenance Provenance,
) (Bundle, error)
    NewBundle checks supplied-count bounds, nonempty provenance,
    portable identity collisions and the root-reachable dependency closure
    (depth/edges/cycles). Extra unreachable schemas are retained but their
    separate closures are not traversed. Identical portable schemas can replace
    each other's provider/metadata coordinates because those fields are outside
    identity. No origin authentication, cancellation or aggregate retained-byte
    limit is added.

func (bundle Bundle) MarshalBinary() ([]byte, error)
    MarshalBinary returns a deterministic, versioned offline artifact. Loading
    recompiles every definition; the artifact never authorizes network access.

func (bundle Bundle) Provenance() Provenance
    Provenance returns the immutable bundle source metadata.

func (bundle Bundle) Resolve(fingerprint Fingerprint) (Schema, bool)
    Resolve returns a schema solely from the immutable local bundle.

func (bundle Bundle) Root() Schema
    Root returns the bundle root schema.

type Client struct {
	// Has unexported fields.
}
    Client validates portable requests against provider capabilities and
    caller bounds before provider I/O. Methods are safe concurrently only
    if the supplied provider is; there are no owned background goroutines or
    Close operation. Slot waits are context-aware, but arbitrary callbacks
    are not preempted or panic-contained. Zero/nil clients are not usable;
    use NewClient.

func NewClient(provider Provider, limits Limits) (*Client, error)
    NewClient rejects typed-nil providers/nonpositive limits, captures a copied
    capability snapshot and borrows the provider for the client's lifetime.
    It invokes Capabilities synchronously and does not own transport shutdown.

func (client *Client) Capabilities() Capabilities
    Capabilities returns a defensive copy of the snapshot captured at NewClient.

func (client *Client) CheckCompatibility(
	ctx context.Context,
	request CompatibilityRequest,
) (CompatibilityResult, error)
    CheckCompatibility returns an explicit unsupported result without provider
    I/O when the requested semantics are unavailable.

func (client *Client) Delete(ctx context.Context, request DeleteRequest) (DeleteResult, error)
    Delete requires an exact portable fingerprint guard for both soft and
    hard deletion, then delegates only to an advertised provider capability.
    The provider owns comparison and service atomicity; Client does not resolve
    the target itself. Transitional results and partial evidence on error are
    allowed.

func (client *Client) List(ctx context.Context, request ListRequest) (ListPage, error)
    List delegates only when the provider advertises bounded listing and the
    request fits caller limits.

func (client *Client) Register(ctx context.Context, request RegisterRequest) (RegisterResult, error)
    Register validates raw-content bounds/format before provider I/O and
    coalesces overlapping requests by Subject/Fingerprint. The leader runs
    synchronously under its context; waiters may cancel without canceling it.
    A full new-leader budget fails with ErrLimitExceeded before dispatch.
    This is not persistent or cross-process idempotency. Provider callbacks must
    not panic: registration owner/slot cleanup assumes normal return, so panic
    can leave admission occupied. Provider errors/results and uncertain effects
    may be returned together; nil error can still accompany RegistrationUnknown.

func (client *Client) Resolve(ctx context.Context, lookup Lookup) (ResolveResult, error)
    Resolve rejects unsupported/invalid selectors, then validates
    nonzero compiled fingerprint, ID namespace, declared lifecycle and
    selector agreement. It does not independently enforce all response
    size/format/version-capability fields. Partial provider results can
    accompany an error; fixed default error text retains deliberate cause
    inspection. Nil error does not require available lifecycle.

type Clock interface {
	// Now returns cache-policy time; calls can be concurrent and are not preempted.
	Now() time.Time
}
    Clock supplies deterministic cache time.

type CodecIntegration struct {
	// Has unexported fields.
}
    CodecIntegration composes a business codec and provider framer without
    a built-in registry dependency. Borrowed collaborators must uphold the
    no-hidden registry contract; no sandbox, panic recovery or callback
    preemption is added. Concurrent reuse depends on codec/framer safety.
    It owns no Close lifecycle.

func NewCodecIntegration(
	codec ValueCodec,
	framer Framer,
	limits CodecLimits,
) (*CodecIntegration, error)
    NewCodecIntegration validates explicit codec and framing bounds.

func (integration *CodecIntegration) Decode(
	ctx context.Context,
	schema Schema,
	message WireMessage,
	target any,
) error
    Decode applies an already-resolved schema to one parsed payload. Registry
    discovery is not supplied by this wrapper and is prohibited by the codec
    contract, not mechanically prevented. Decode does not bind message.ID to
    schema.Fingerprint; the caller must resolve and match that identity first.
    It copies payload but borrows target, whose partial mutation on error is
    codec-defined.

func (integration *CodecIntegration) Encode(
	ctx context.Context,
	schema Schema,
	id ProviderID,
	value any,
) ([]byte, error)
    Encode serializes against an explicit schema, checks payload bounds,
    and frames with an explicit provider ID.

func (integration *CodecIntegration) Parse(
	ctx context.Context,
	framed []byte,
) (WireMessage, error)
    Parse validates the complete frame bound before delegating to the explicit
    provider framer. It never resolves the returned ID.

type CodecLimits struct {
	// MaxPayloadBytes is positive; encoding checks it after codec allocation,

	// MaxFrameBytes must be at least MaxPayloadBytes; parsed input is checked
	// before Unframe, encoded output after framing allocation.
	MaxFrameBytes int
}
    CodecLimits bound both business payloads and complete framed messages.

type CompileLimits struct {
	// MaxSchemaBytes caps content and, independently, total reference text and
	// metadata text before copying; it is not a combined allocation budget.
	MaxSchemaBytes int
	// MaxCanonicalBytes caps returned canonical bytes after collaborator work.
	MaxCanonicalBytes int
	// MaxReferences caps named reference count; each fingerprint must be nonzero.
	MaxReferences int
	// MaxMetadata caps entry count; all limits must be positive, not zero-defaulted.
	MaxMetadata int
}
    CompileLimits bound hostile schema definitions before and after format

func DefaultCompileLimits() CompileLimits
    DefaultCompileLimits returns conservative portable bounds. Provider adapters
    may impose stricter service limits. Content/canonical bytes and each
    reference/ metadata text aggregate default to 1MiB; reference and metadata
    counts to 256.

type Provider interface {
	// Capabilities must return stable advertised semantics and copied slices or
	// caller-safe snapshots. NewClient captures a defensive copy once.
	Capabilities() Capabilities
	// Register must preserve scoped identity and creation/outcome uncertainty;
	// cooperate with context, and make retries/idempotency policy explicit.
	Register(context.Context, RegisterRequest) (RegisterResult, error)
	// Resolve must return selector-consistent compiled schema/ID/lifecycle;
	// partial results on error are permitted but not automatically trusted.
	Resolve(context.Context, Lookup) (ResolveResult, error)
	// CheckCompatibility must distinguish unsupported/indeterminate from compatible
	// and keep diagnostics distinct from default errors. Returned slices remain
	// implementation-owned; caller logging/privacy policy still applies.
	CheckCompatibility(context.Context, CompatibilityRequest) (CompatibilityResult, error)
}
    Provider is the narrow remote-provider boundary used by Client.

type ReferenceGraph struct {
	// Has unexported fields.
}
    ReferenceGraph is an immutable validated provider-coordinate graph.

func BuildReferenceGraph(
	ctx context.Context,
	roots []ReferenceCoordinate,
	resolver ReferenceResolver,
	limits GraphLimits,
) (ReferenceGraph, error)
    BuildReferenceGraph visits roots/edges in input order, copies each
    first-visit document and rejects mismatched nodes, cycles, missing
    references and limits. Counts/depth are graph admission, not a cap on
    root input/callback allocations. Context is checked before visits and
    passed through, not forcibly enforced inside the resolver; failure returns
    no partial graph. No goroutines or close ownership are introduced. See
    reference_graph_test.go for DAG/cycle boundaries.

func (graph ReferenceGraph) Documents() []ReferenceDocument
    Documents returns a deep copy in deterministic first-visit order.

	RegistrationExisting RegistrationOutcome = "existing"

	RegistrationRejected RegistrationOutcome = "rejected"

	RegistrationUnauthorized RegistrationOutcome = "unauthorized"

	RegistrationUnavailable RegistrationOutcome = "unavailable"
	// RegistrationUnknown reports that the provider effect cannot be determined.

type ResolveCache struct {
	// Has unexported fields.
}
    ResolveCache is a bounded positive and negative cache. A single caller owns
    each synchronous upstream load; waiters may cancel independently. It starts
    no goroutines. Methods synchronize internal state, not injected resolver,
    Clock or Observer. Use NewResolveCache; zero/nil caches are unusable. It
    borrows dependencies, owns no Close/transport cleanup, and does not recover
    load panics. A resolver panic can leave a retained flight unfinished even
    after its slot is released; require panic-free collaborators to preserve
    admission/cleanup.

func NewResolveCache(resolver Resolver, config ResolveCacheConfig) (*ResolveCache, error)
    NewResolveCache validates and constructs a cache.

func (cache *ResolveCache) Invalidate(lookup Lookup) error
    Invalidate removes cached state and detaches the current flight generation.
    It does not cancel the old leader or prevent its existing waiters receiving
    that result; completion cannot repopulate this selector. Detached leaders
    still consume MaxConcurrent admission until they finish. Removal is logical,
    not secure erasure of copied schemas retained by callers or older flights.

func (cache *ResolveCache) Prime(lookup Lookup, result ResolveResult) error
    Prime adds one explicitly preloaded positive result without provider I/O. It
    is fresh for the configured freshness interval and remains eligible for the
    configured stale interval. It validates selector/result agreement and fences
    older storage writes without canceling their callers. The result Schema is
    immutable, but no new content-byte admission or provenance authentication is
    added.

func (cache *ResolveCache) Resolve(
	ctx context.Context,
	lookup Lookup,
	policy AvailabilityPolicy,
) (resolution CacheResolution, err error)
    Resolve applies one explicit availability policy. Fresh/negative/cache-only
    paths avoid upstream I/O; only ErrUnavailable permits AllowStale fallback.
    Each caller samples its own entry/time before joining or starting a
    synchronous flight, so stale eligibility/age is not remeasured after a long
    load. Waiters can cancel independently; the leader's context controls shared
    upstream work. Invalidating/priming fences storage, not results already
    awaited by old callers. Observer calls follow even canceled/failed paths and
    may delay return.

type ResolveCacheConfig struct {
	// MaxEntries bounds retained entry count, not schema bytes or waiter count.
	MaxEntries int
	// MaxConcurrent bounds upstream calls and retained load leaders, including
	// leaders detached by Invalidate or Prime. Same-key waiters share a leader.
	MaxConcurrent int
	// FreshFor is positive freshness after store/prime.
	FreshFor time.Duration
	// StaleFor is nonnegative extra eligibility after freshness; caller must keep
	// FreshFor+StaleFor representable as a duration.
	StaleFor time.Duration
	// NegativeFor is positive authoritative-absence retention.
	NegativeFor time.Duration
	// Clock is required and borrowed; Now must be concurrent-safe/prompt and
	// returns caller-defined cache time with no monotonic/timeout guarantee.
	Clock Clock
	// Observer is optional and borrowed; callbacks run synchronously after every
	// Resolve path, outside locks. Panics are recovered, blocking is not canceled.
	Observer ResolveCacheObserver
}
    ResolveCacheConfig makes cache bounds and freshness policy explicit.

type ResolveCacheEvent struct {
	// State is the sampled cache outcome and can be empty on early failure.
	State CacheState
	// Outcome is success or error; it carries no selector or payload.
	Outcome string
}
    ResolveCacheEvent excludes schema contents, subjects, IDs, and credentials.

type ResolveCacheObserver interface {
	// ObserveResolveCache receives only bounded state/category fields. It must
	// return promptly and be concurrent-safe; no goroutine/deadline is added.
	ObserveResolveCache(context.Context, ResolveCacheEvent)

    ResolveCacheObserver receives bounded metadata after each lookup. It must
    not assume calls are serialized and must not retain request contexts.

	ctx context.Context,
	schema schemaregistry.Schema,
	payload []byte,
	target any,
) error

    target. On validation failure target is untouched by this adapter; custom
    unmarshal callbacks or conversion errors can partially mutate it afterward.
    Those calls are not context-preempted or panic-contained. Retained causes
    are trusted inspection data, not safe log text; no secure erasure is
    supplied.

func (adapter *Adapter) Encode(ctx context.Context, schema schemaregistry.Schema, value any) ([]byte, error)

    the supplied schema. json.Marshaler callbacks may allocate/block/panic

    locally; there is no provider lookup or promise of a total allocation bound.
