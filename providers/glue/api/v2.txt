package glue // import "github.com/faustbrian/go-schema-registry/providers/glue/v2"

Package glue adapts AWS Glue Schema Registry through an explicitly
configured SDK v2 API, preserving registry/schema names, scoped
UUIDs and lifecycle state. New/UncompressedFramer compose service and
header-version-3 wire work separately; no credentials, endpoints, SDK client,
retry loop or shutdown is discovered/owned. This module retains root
/v2 types, distinct from root/Confluent /v3. The source authority pins
SDK API1.152.0 and Java SerDe1.1.27; actual dependencies are in go.mod.
References/listing/deletion/candidate dry-run and ZLIB are unsupported.
See GLUE-DEC-001..003; faithful SDK/wire evidence is not live AWS qualification.

TYPES

type API interface {
	// GetSchemaByDefinition must preserve the configured target and definition
	// lookup semantics, return owned/copyable response fields and honor ctx.
	GetSchemaByDefinition(context.Context, *awsglue.GetSchemaByDefinitionInput, ...func(*awsglue.Options)) (*awsglue.GetSchemaByDefinitionOutput, error)
	// RegisterSchemaVersion must preserve SDK mutation/uncertainty semantics;
	// idempotent duplicates do not prove which concurrent request created a version.
	RegisterSchemaVersion(context.Context, *awsglue.RegisterSchemaVersionInput, ...func(*awsglue.Options)) (*awsglue.RegisterSchemaVersionOutput, error)
	// GetSchemaVersion must honor exact UUID or registry/name/version selectors
	// and ctx; SDK/transport owns HTTP response allocation and cleanup.
	GetSchemaVersion(context.Context, *awsglue.GetSchemaVersionInput, ...func(*awsglue.Options)) (*awsglue.GetSchemaVersionOutput, error)
}
    API is the narrow AWS SDK v2 boundary used by Provider. Configure SDK retry,
    endpoint, region, and credentials explicitly when constructing its client;
    Provider adds one total context timeout and does not add a second retry
    loop.

type Config struct {
	// API is required and borrowed, already configured for credentials, endpoint,
	// region, retries and transport cleanup. It must honor ctx and be concurrent-safe.
	API API
	// Scope is a required caller-defined region/account/registry namespace; the
	// adapter does not authenticate it against returned UUIDs.
	Scope string
	// RequestTimeout is positive and includes slot waits/API work for cooperative
	// SDK callbacks; arbitrary injected API calls cannot be forcibly stopped.
	RequestTimeout time.Duration
	// MaxConcurrent is a positive per-provider call budget, not a whole-process
	// waiter/byte bound. No extra SDK retry loop is introduced.
	MaxConcurrent int
	// Canonicalizers is copied as a map, but implementations are borrowed and
	// must be local-only and safe concurrently; references are not fetched/injected.
	Canonicalizers map[schemaregistry.Format]schemaregistry.Canonicalizer
}
    Config binds one AWS region/account/registry scope to explicit schema format
    implementations.

type Provider struct {
	// Has unexported fields.
}
    Provider is safe for concurrent use when the supplied AWS SDK client and
    every supplied canonicalizer are safe for concurrent calls.

func New(config Config) (*Provider, error)
    New validates supplied policy and copies the canonicalizer map/capability
    snapshot without constructing an SDK client or performing AWS I/O.
    Collaborators remain borrowed; no owned background goroutine or Close
    operation is supplied.

func (provider *Provider) Capabilities() schemaregistry.Capabilities
    Capabilities returns a defensive copy of the configured AWS Glue profile.

func (provider *Provider) CheckCompatibility(context.Context, schemaregistry.CompatibilityRequest) (schemaregistry.CompatibilityResult, error)
    CheckCompatibility is explicit unsupported because Glue applies configured
    compatibility while registering and exposes no candidate dry-run with the
    same semantics.

func (provider *Provider) Register(ctx context.Context, request schemaregistry.RegisterRequest) (schemaregistry.RegisterResult, error)
    Register rejects missing registry/name, empty or oversized schema text and
    references, then performs exact-definition lookup before registration.
    A UUID returned by a new call may be an existing concurrent version,
    so nil error can accompany RegistrationUnknown; unavailable mutation
    outcomes remain uncertain. The 170000-byte definition check follows
    Schema.Definition's defensive copy, not all SDK/transport allocations or
    service mutation atomicity.

func (provider *Provider) Resolve(ctx context.Context, lookup schemaregistry.Lookup) (schemaregistry.ResolveResult, error)
    Resolve loads one version by scoped UUID, registry/name numeric version or
    latest. It checks UUID grammar/expected version and caps returned definition
    text at 170000 bytes after SDK materialization, not the whole HTTP response.
    Available, pending, deleting, failed and unknown lifecycle remain explicit;
    nil error does not imply availability. UUID grammar does not enforce
    variant, UUID version or authenticated account/registry membership.

type UncompressedFramer struct {
	// Has unexported fields.
}
    UncompressedFramer implements AWS Glue header version 3 with compression
    byte 0 and a 16-byte schema-version UUID. ZLIB byte 5 is rejected
    explicitly. Frame/Unframe perform no SDK calls, copy output bytes and
    validate grammar, not UUID variant/version or payload authenticity. Scope is
    caller metadata. Use NewUncompressedFramer; nil/zero-value receivers are not
    supported.

func NewUncompressedFramer(scope string, maxPayloadBytes int) (*UncompressedFramer, error)
    NewUncompressedFramer constructs a bounded AWS Glue uncompressed framer.

func (framer *UncompressedFramer) Frame(ctx context.Context, id schemaregistry.ProviderID, payload []byte) ([]byte, error)
    Frame writes an AWS Glue header-version-3 frame with compression byte zero.

func (framer *UncompressedFramer) Unframe(ctx context.Context, framed []byte) (schemaregistry.ProviderID, []byte, error)
    Unframe parses an uncompressed AWS Glue frame and returns an owned payload
    copy.
